First PadStudio release with a native controller layout editor, saved profiles, action layers, game associations, and profile backup/import.

Maps controller input to taps, held touches, swipes, and Android navigation. Includes touch joystick/camera modes, two-stage triggers, device gyro touch aiming, a controller tester, and an on-screen target picker.

Requires Android 11+. Analog motion capture requires Android 14+ and a running, authorized Shizuku connection. Enable PadStudio in accessibility settings, save a layout, and start mapping. Use the touch playground to verify a mapped input. Touch output targets the primary display.

Obtainium source: https://github.com/BrianCodez/PadStudio

This version uses the device gyro. Controller gyro protocols, native keyboard/mouse injection, Steam imports, arbitrary macros, flick stick, and radial menus are not included. Physical controller and device gyro compatibility still require handheld validation.
